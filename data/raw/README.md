# Raw Dataset

This folder contains the original CSV supplied for the project:

- **Dataset:** Web page phishing detection
- **Original authors:** Abdelhakim Hannousse and Salima Yahiouche
- **Version:** 3
- **Published:** 25 June 2021
- **Canonical source:** https://data.mendeley.com/datasets/c2gw7fy2j4/3
- **DOI:** https://doi.org/10.17632/c2gw7fy2j4.3
- **Dataset licence:** Creative Commons Attribution 4.0 International (CC BY 4.0)

The CSV is included unchanged. See [`../../docs/DATASET_ATTRIBUTION.md`](../../docs/DATASET_ATTRIBUTION.md)
for attribution and licence information.

**Safety note:** The `url` column contains website addresses from a historical phishing benchmark.
Do not open or visit these URLs. The project analyses the supplied feature values and does not
connect to the listed websites.
